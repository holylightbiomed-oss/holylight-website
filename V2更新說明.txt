義光生醫網站 V2.0 更新步驟

請先解壓縮 ZIP。

【需要上傳的項目】
1. index.html
2. styles.css
3. script.js
4. README.md
5. assets 資料夾（內含 hlb-mark.svg）

【GitHub 操作】
1. 打開 holylight-website Repository
2. 點 Add file
3. 點 Upload files
4. 把上述所有檔案與 assets 資料夾拖曳進去
5. 頁面下方點 Commit changes
6. 等待 GitHub Pages 自動更新，約 1～3 分鐘
7. 重新整理：
https://holylightbiomed-oss.github.io/holylight-website/

提醒：
- 不需要重新設定 GitHub Pages。
- 原本的 index.html、styles.css、README.md 會被新版本覆蓋。
- GitHub 若出現同名檔案提示，這是正常現象。
