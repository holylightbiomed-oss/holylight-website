# 義光生醫官方網站 V2.0

這是 Holy Light Biomedical Co., Ltd. 的企業官網第二版。

## 主要檔案

- `index.html`：網站內容
- `styles.css`：版面、配色、響應式設計與動畫
- `script.js`：行動選單、滾動動畫、回到頂端
- `assets/hlb-mark.svg`：網站品牌圖形

## 更新到 GitHub Pages

1. 進入 `holylightbiomed-oss/holylight-website`
2. 點選 **Add file → Upload files**
3. 將本資料夾內的所有檔案與 `assets` 資料夾拖曳上傳
4. GitHub 若提示同名檔案，允許覆蓋
5. 點 **Commit changes**
6. 等待約 1～3 分鐘，再重新整理網站
